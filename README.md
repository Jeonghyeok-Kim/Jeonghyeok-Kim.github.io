# Jeonghyeok Kim — personal academic website

Live at https://jeonghyeok-kim.github.io/ (built automatically by GitHub Pages).

## How to update

Edit any file on github.com: open it, click the pencil icon, change the text, then **Commit changes**. The site updates in 1–2 minutes.

| What you want to change | File |
|---|---|
| Title, affiliation, email, Google Scholar, CV link | `_config.yml` (the `profile:` block) |
| Home page introduction | `index.md` |
| Papers (add, move, edit links/abstracts) | `_data/papers.yml` |
| Teaching | `teaching.md` |
| Colors and fonts | `assets/css/main.css` (top of the file) |

**Upload a new PDF or CV:** open the `assets` folder → **Add file → Upload files**. Uploading a file with the same name (e.g. `CV.pdf`) replaces the old one.

**Profile photo:** upload a photo named `profile.jpg` into `assets/img/`.

**Do not delete** `google872eae9976672bdd.html` — it keeps the site verified in Google Search Console.
